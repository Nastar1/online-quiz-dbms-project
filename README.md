# Online Quiz Platform — DBMS Project

## 📌 Project Overview
This is an online quiz platform developed as part of a 2nd-year Database Management Systems (DBMS) course. The platform allows users to take quizzes by subject, supports both single and multiple correct answers, and enables result tracking through an admin-controlled system.

## Team Members
Developed by a team of three second-year undergraduate students.

## Key Features
- Subject-wise quiz selection  
- User registration and login  
- Admin panel to add, update, and delete quizzes/questions  
- Result storage and retrieval  
- Support for single and multiple correct answers  

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Django)  
- **Database:** MySQL
